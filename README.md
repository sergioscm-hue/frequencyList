# Lista de Chamada

App instalável (PWA) para registro de presença de alunos, com funcionamento offline e sincronização com uma Planilha Google via Google Apps Script.

- `index.html`, `sw.js`, `manifest.json`, `icons/`: o aplicativo.
- Este repositório **não contém** dados de alunos, a URL da planilha nem o código de acesso: na primeira abertura, o app pede a URL do Apps Script e o código, e os guarda apenas no aparelho.
